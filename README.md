# Fretboard

An interactive guitar fretboard visualization tool for exploring scales and chords.

## Features

- Search scales and chords by name with autocomplete
- Visual fretboard display with note highlighting
- Toggle between note names (A–G) and interval names (R, m3, M3, etc.)
- Add/remove strings and tune them up or down
- Related scales/chords panel

## Stack

- [Vite](https://vitejs.dev/) — dev server and build tool
- [Backbone.js](https://backbonejs.org/) — MVC framework
- [jQuery](https://jquery.com/) + [Underscore.js](https://underscorejs.org/)

## Getting Started

```bash
pnpm install
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Build

```bash
pnpm build
```

Output goes to `dist/`.
